⚙️ ตั้งค่าโปรไฟล์และระบบแอดมิน

แก้ไขข้อมูลความปลอดภัยสำหรับบัญชีแอดมิน หรือรีเซ็ตข้อมูลทั้งหมดในร้านค้า

🛡️ ข้อมูลบัญชีผู้ดูแลระบบ (Admin Credentials)

💬 ตั้งค่าการแจ้งเตือนไลน์จริง (LINE Bot Notifications)

ระบุข้อมูล Channel Access Token ของ LINE Messaging API เพื่อส่งข้อความเตือนสถานะไปยังหน้าจอมือถือจริงของลูกค้า

🔑 ตั้งค่าการเข้าสู่ระบบด้วย Google (Google OAuth Settings)

ระบุรหัส Google Client ID ที่ได้จาก Google Cloud Console เพื่อเปิดใช้งานปุ่มสมัครสมาชิกและล็อกอินผ่าน Google บัญชีจริง

⚠️ พื้นที่อันตรายมาก (Dangerous System Settings)

การรีเซ็ตระบบจะเป็นการล้างประวัติสะสมแต้ม ลบสมาชิกทั้งหมด และหักแต้มสะสมออกอย่างถาวร ไม่สามารถกู้กลับคืนมาได้อีก

*โปรดระมัดระวังเป็นอย่างสูง

ระบบสะสมแต้มและฐานข้อมูลทั้งหมดของร้านจะถูกล้างค่าเริ่มต้นใหม่ทั้งหมด
